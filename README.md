# Roblox Deals Telegram Bot

Telegram-бот, который ищет **выгодные предложения** по предметам из игр
**Blox Fruits**, **MM2** и **YBA** на маркетплейсах **GGSel.net**, **FunPay** и **PlayerOK** и присылает
украшенные карточки со ссылкой на лот.

## Как это работает

1. Каждую минуту бот ищет лоты по каждому предмету из списка на трёх площадках: поиск GGSel, страницы лотов FunPay и каталог PlayerOK.
2. Лот считается сделкой, если он **дешевле цены, указанной вами в `config.py`** —
   других ориентиров нет: сравнения с рынком и уведомления об изменении цен
   убраны полностью.
   (Переключатель `REQUIRE_TARGET_PRICE = False` вернёт старое правило
   «скидка 20%+ от рынка **или** дешевле вашей цены».)
3. Каждое предложение уходит отдельной карточкой в Telegram (в `NOTIFY_USER_IDS` и подписчикам игры).
4. Сделки сохраняются в SQLite: анти-дубль и очередь на случай недоступности Telegram.

Одни и те же лоты не дублируются: уведомление приходит **один раз**.

## Возможности

- 🔍 **Реальные лоты** — три площадки: GGSel (поиск), FunPay (страницы игр), PlayerOK (API каталога)
- 💵 **Ориентир — ваши цены** — в карточке цена лота и ваш лимит из `config.py`, без сравнений с рынком
- 🎯 **Фильтр по вашим ценам** — приходят только лоты дешевле цен из `config.py`
- 🏷 **Полное название лота** — в карточке имя товара, как его написал продавец
- 🔔 **Подписки на игры**, уведомления подписчикам и `NOTIFY_USER_IDS`
- 📋 **Свой список товаров** — через `/additem` прямо в боте или в `config.py`
- 💡 **Автопредложение** — часто встречаемый товар (100–2000 ₽) бот предлагает добавить (✅/❌)
- 💻 **Запуск на своём ПК** — двойной клик по «Запуск бота.bat», дальше работает сам
- 🔐 **Белый список** — ботом пользуются только разрешённые ID
- 🛡 **Защита от спама** — дубли лотов отсекаются, на игру ≤5 карточек за рассылку

## Команды

| Команда | Описание |
|---|---|
| `/start` | Главное меню |
| `/help` | Помощь |
| `/subscribe`, `/unsubscribe` | Подписка / отписка от уведомлений |
| `/check` | Проверить цены прямо сейчас |
| `/deals` | Последние выгодные предложения |
| `/myitems` | Мои товары |
| `/additem <игра> <название> <цена>` | Добавить товар: `/additem mm2 Harvester 500` |
| `/adduser`, `/removeuser`, `/whitelist`, `/togglewhitelist` | Админ: белый список |

Игры в `/additem`: `blox`, `mm2`, `yba`.

> ⚠️ Команды и кнопки работают в интерактивном режиме (`py -3 bot.py`).
> В режиме GitHub Actions бот только шлёт уведомления: свой список
> редактируйте в `config.py` на сайте GitHub, ручной проверкой служит
> кнопка *Run workflow*.

## Быстрый старт (Windows)

```bat
py -3 -m pip install -r requirements.txt
py -3 bot.py
```

Токен уже лежит в `.env` (`BOT_TOKEN=...`), его менять не нужно.

> Если Telegram недоступен из вашей сети (таймауты `api.telegram.org`),
> добавьте в `.env` строку `PROXY_URL=socks5://127.0.0.1:1080`
> (адрес вашего прокси) — бот пойдёт через него.

## Настройка

### Свой список товаров

**В боте (рекомендуется):**
```
/additem mm2 Harvester 500
/additem blox Dought Fruit 45
```

**В коде** — `config.py`, блок `GAMES`:

```python
GAMES = {
    "blox_fruits": {
        "name": "Blox Fruits",
        "items": {
            # Название: МАКСИМАЛЬНАЯ цена в ₽ — уведомление приходит,
            # только когда лот дешевле этой цены
            "Dought Fruit": 45,
            "Dragon Fruit": 1000,
        }
    },
    ...
}
```

### Настройки — `config.py`

```python
CHECK_INTERVAL_MINUTES = 5   # как часто проверять
PRICE_THRESHOLD_PERCENT = 20  # мин. скидка vs рынок
SUGGEST_ITEM_MIN_PRICE = 100  # диапазон цен для автопредложения
SUGGEST_ITEM_MAX_PRICE = 2000
WHITELIST_USERS = [8680512428]  # кто может пользоваться ботом
```

## Запуск на своём ПК (основной режим)

Двойной клик по **`Запуск бота.bat`** (или `py -3 run_local.py`) — и бот сам
проверяет цены **каждую минуту** и присылает каждую новую анкету **отдельным
сообщением** — но только те, что дешевле цены из `config.py`.
Уведомления об изменении цен убраны: только сделки.

Если Telegram из вашей сети не работает — сообщения уходят **в Discord**
(вебхук в `.env`: `DISCORD_WEBHOOK_URL`). Можно также включить свой
VPN/прокси-клиент: бот найдёт его сам (порты 10809/10808/7890…) или задайте
`PROXY_URL` в `.env` — тогда сообщения пойдут в Telegram. Если недоступны оба
канала, сделки копятся в очереди и отправятся позже.
Окно можно свернуть; закрыли окно — бот остановлен.

💡 Если какой-то товар **часто выставляют** (10+ появлений) и он стоит **100–2000 ₽** —
бот пришлёт подсказку «Часто выставляют: …», чтобы вы добавили его в `items`
в `config.py`. Уже отслеживаемые товары не предлагаются, каждый товар
предлагается один раз, не больше 10 подсказок в день.

## Запуск в облаке (бесплатно, без ПК)

**GitHub Actions** — 0 ₽, без карты. Автоматическое расписание отключено
(бот работает локально), запуск вручную: кнопка *Run workflow*.

Режим действий: уведомления работают; команды/кнопки в Telegram —
нет (вместо них: кнопка *Run workflow* на GitHub и правка `config.py`
через сайт GitHub).

Остальные варианты (Railway, Render, бесплатный VPS Oracle) — в [HOSTING.md](HOSTING.md).

## Важно

⚠️ **Сопоставление строгое**: лот засчитывается только если в его названии есть
маркер игры (`Blox Fruits`/`BF`/`фрукт`, `MM2`/`Murder Mystery`, `YBA`/`Bizarre`).
Так чужие игры (King Legacy, Grow a Garden) не попадают в уведомления.

⚠️ **Запросы с паузами** (0.8 с между запросами) — не нагружаем маркетплейс.

⚠️ **SQLite в облаке**: файл `deals.db` переживает перезапуски, но сбрасывается
при redeploy, если не подключить диск. Список товаров из `config.py` и белый
список хранятся в коде и никуда не деваются.
